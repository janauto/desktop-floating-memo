# 桌面浮窗备忘录

桌面浮窗备忘录是一个基于 Electron 的 macOS 桌面效率工具。它把轻量任务清单、桌面置顶浮窗、番茄时钟、任务计时、经验值、等级、连击、成就和数据看板整合在一个透明悬浮窗口中，适合需要随时记录待办、快速清空小任务、追踪个人执行节奏的日常工作流。

项目当前版本定位为「游戏化任务管理工具」：用户不是只勾掉待办，而是通过完成任务获得 XP、触发动效、积累统计，并在控制中心查看个人效率数据。

## 核心特性

- 无边框透明浮窗：默认显示在桌面右上角，支持置顶、拖拽、折叠和失焦透明。
- 任务快速记录：输入任务后按 Enter 添加，支持普通、重要、紧急三档优先级。
- 标签筛选：内置 `需求`、`会议`、`想法`、`Bug`，并可在设置中维护自定义标签。
- 单任务计时：每个任务从创建开始计时，支持暂停和继续，并按耗时显示不同状态颜色。
- 拖拽排序：任务卡片可以直接拖拽调整顺序。
- 游戏化完成机制：完成任务会获得 XP、触发粒子爆炸、屏幕震动、连击和成就提示。
- 番茄时钟：内置专注、短休、长休三种模式，支持 4 轮专注后进入长休。
- 数据看板：统计今日完成、本周完成、完成率、累计经验、活跃时段和最近 7 日趋势。
- 控制中心：提供全局参数、外观、标签、终端式配置入口。
- 系统托盘：可通过托盘显示/隐藏窗口、切换置顶状态或退出应用。
- 本地持久化：任务和游戏状态使用 `electron-store` 保存，历史统计使用 SQLite 保存。

## 技术栈

| 模块 | 技术 |
| --- | --- |
| 桌面框架 | Electron |
| 主进程 | Node.js CommonJS |
| 渲染层 | HTML、CSS、原生 JavaScript |
| 设置存储 | electron-store |
| 历史数据库 | better-sqlite3 |
| 打包工具 | electron-builder |
| 原生模块重建 | electron-rebuild |

## 模块说明

### `main.js`

Electron 主进程入口，负责创建主浮窗、设置窗口、系统托盘以及所有 IPC 通道。

主要职责：

- 创建透明、无边框、置顶、跳过任务栏的主窗口。
- 默认将主窗口放在屏幕右上角，并保存用户移动后的位置。
- 实现折叠/展开窗口，高度在标题栏模式和完整模式之间切换。
- 处理失焦透明、聚焦恢复不透明等窗口行为。
- 创建设置窗口并支持关闭和全屏切换。
- 创建 macOS 托盘菜单，支持显示/隐藏、始终置顶和退出。
- 暴露任务、游戏状态、设置和数据库相关 IPC。

### `db.js`

SQLite 历史数据层，基于 `better-sqlite3`，数据库文件写入 Electron 的 `userData` 目录。

保存的数据包括：

- 任务 ID、正文、优先级、标签。
- 创建、完成、删除时间。
- 累计耗时。
- 任务状态：active、completed、deleted。
- 完成任务获得的 XP。

统计能力包括：

- 累计完成数。
- 今日完成数。
- 最近 7 日完成数。
- 总创建数和删除数。
- 平均任务耗时。
- 累计 XP。
- 按优先级分布。
- 按小时完成分布。
- 最近 7 日趋势。
- 按标签完成分布。
- 完成率。

### `renderer/app.js`

主浮窗的核心前端逻辑。

主要职责：

- 加载和保存任务、游戏状态、设置。
- 添加、删除、完成任务。
- 处理优先级选择、标签筛选、任务拖拽排序。
- 管理每个任务的运行中/暂停计时状态。
- 维护 XP、等级、今日完成数、总完成数和连击数。
- 判断并展示成就。
- 触发粒子爆炸、屏幕震动、等级提升浮层和成就提示。
- 初始化实时时钟、励志语录和番茄时钟。
- 根据内容高度动态调整 Electron 窗口高度。

### `renderer/pomodoro.js`

番茄时钟模块。

默认配置：

| 模式 | 默认时长 | 说明 |
| --- | --- | --- |
| 专注 | 25 分钟 | 工作专注时间 |
| 短休 | 5 分钟 | 短暂休息 |
| 长休 | 15 分钟 | 完成 4 轮专注后的长休 |

功能行为：

- 支持开始、暂停、重置、跳过。
- 支持专注、短休、长休手动切换。
- 运行中显示 SVG 环形进度。
- 每完成一轮专注奖励 15 XP。
- 完成后播放提示音并自动进入下一阶段。
- 4 轮专注后进入长休。
- 可收起番茄时钟主体区域。

### `renderer/settings.js`

控制中心逻辑，负责设置窗口内的页面路由、看板、参数配置和终端。

页面包括：

- 看板分析：今日完成、本周完成、完成率、累计经验、活跃时间段、最近 7 日趋势、效率诊断、励志语录。
- 全局设置：普通/重要/紧急任务 XP、连击时间窗口、始终置顶、屏幕震动。
- 个性化：失焦透明度、标签新增和删除。
- 终端：通过命令查看或修改配置。

终端命令：

| 命令 | 说明 |
| --- | --- |
| `help` | 查看命令列表 |
| `list` | 列出当前全部设置 |
| `get <key>` | 查看单个配置项 |
| `set <key> <value>` | 修改配置项 |
| `clear` | 清空终端输出 |
| `exit` | 关闭设置窗口 |

### `renderer/preload.js`

渲染层和主进程之间的安全桥接层。项目开启了 `contextIsolation` 并关闭 `nodeIntegration`，渲染层通过 `window.api` 调用主进程能力。

暴露能力包括：

- 任务读取和保存。
- 游戏状态读取和保存。
- 窗口折叠、resize、透明度控制。
- 设置读取、保存和更新通知。
- 设置窗口打开、关闭、全屏切换。
- 数据库记录新增、完成、删除、统计和历史查询。

### `renderer/quotes.js`

励志语录库和随机语录函数。主窗口语录默认每 30 分钟刷新一次，控制中心语录默认每 5 分钟刷新一次。

### `renderer/index.html` 与 `renderer/styles.css`

主浮窗界面结构和样式，包含：

- 标题栏、实时钟、等级 badge。
- XP 进度条。
- 统计行。
- 番茄时钟。
- 语录区域。
- 任务输入框、优先级按钮、标签栏。
- 任务列表。
- 成就提示、升级浮层、粒子 canvas。

### `renderer/settings.html` 与 `renderer/settings.css`

控制中心窗口结构和样式，包含 macOS 风格窗口按钮、侧边导航和多页面内容区域。

## 安装与启动

### 环境要求

- macOS 10.15+
- Node.js 16+
- npm 8+

由于项目使用 `better-sqlite3` 原生模块，首次安装或 Electron 版本变化后建议执行 rebuild。

### 安装依赖

```bash
npm install
```

### 重建原生模块

```bash
npm run rebuild
```

### 启动开发版本

```bash
npm start
```

启动后，主浮窗会出现在桌面右上角；托盘区会出现应用图标。

### 打包 macOS 安装包

```bash
npm run build
```

打包配置来自 `package.json` 的 `build` 字段：

- `appId`: `com.memo.floating`
- macOS category: `public.app-category.productivity`
- target: `dmg`

构建成功后会生成可分发的 `.dmg` 文件。

## 使用说明

### 主窗口

- 拖拽标题栏：移动窗口，位置会自动保存。
- 双击标题栏：折叠或展开窗口。
- 点击 `─`：折叠窗口。
- 点击齿轮：打开控制中心。
- 窗口失焦：自动降低透明度。
- 鼠标移入或窗口聚焦：恢复完全不透明。

### 添加任务

1. 在输入框输入任务内容。
2. 选择优先级：
   - 绿色：普通，默认 10 XP。
   - 黄色：重要，默认 20 XP。
   - 红色：紧急，默认 30 XP。
3. 可选择标签筛选项，新任务会使用当前标签。
4. 按 Enter 添加。

### 完成任务

点击任务卡片左侧的闪电按钮完成任务。

完成后会发生：

- 任务卡片播放完成动画。
- 粒子爆炸。
- 可选屏幕震动。
- 增加 XP。
- 更新今日完成和累计完成。
- 如果在连击时间窗口内连续完成，增加 combo。
- 触发等级或成就时显示提示。
- 将任务写入 SQLite 历史记录。

### 删除任务

点击任务卡片右侧的 `x` 删除任务。删除不会获得 XP，但会在 SQLite 中记录为 deleted 状态。

### 任务计时

每个任务都有独立计时器。

- 新任务默认开始计时。
- 点击任务计时器内的暂停按钮可以暂停。
- 再次点击可继续。
- 任务耗时会保存到任务记录中。
- 超过 4 小时和 24 小时会显示不同状态样式。

### 标签筛选

点击标签栏可以筛选当前任务列表。默认标签包括：

- 全部
- 需求
- 会议
- 想法
- Bug

可在控制中心的个性化页面新增或删除标签。

### 拖拽排序

任务卡片支持拖拽排序，松开后会保存新的任务顺序。

### 番茄时钟

支持三种模式：

- 专注：25 分钟。
- 短休：5 分钟。
- 长休：15 分钟。

控制按钮：

- 开始/暂停。
- 重置。
- 跳过当前阶段。
- 收起/展开番茄时钟区域。

完成专注阶段后：

- 奖励 15 XP。
- 更新等级进度。
- 播放提示音。
- 自动进入短休或长休。

### 控制中心

点击主窗口齿轮按钮打开控制中心。

控制中心提供 4 个页面：

- 看板分析：查看完成数据、趋势和效率诊断。
- 全局设置：调整 XP、连击时间、置顶、震动。
- 个性化：调整失焦透明度和标签。
- 终端：用命令方式查看和修改配置。

### 系统托盘

托盘菜单提供：

- 显示/隐藏主窗口。
- 切换始终置顶。
- 退出应用。

## 数据存储

项目使用两层本地存储。

### `electron-store`

保存当前运行状态：

- 当前未完成任务列表。
- 游戏状态。
- 窗口位置。
- 设置参数。

默认设置包括：

- `comboWindow`: 5000
- `xpPerLevel`: 100
- `xpNormal`: 10
- `xpImportant`: 20
- `xpUrgent`: 30
- `blurOpacity`: 0.55
- `alwaysOnTop`: true
- `showClock`: true
- `showTaskTimer`: true
- `particleCount`: 24
- `screenShake`: true
- `tags`: `需求`、`会议`、`💡想法`、`🐛Bug`

### SQLite

保存历史记录和统计数据，数据库文件名为：

```text
memo_history.db
```

文件位置在 Electron 的 `app.getPath('userData')` 目录下。macOS 通常位于：

```text
~/Library/Application Support/<应用名>/memo_history.db
```

历史表为 `task_history`，用于控制中心看板统计。

## 游戏化规则

### XP

默认 XP：

| 类型 | XP |
| --- | --- |
| 普通任务 | 10 |
| 重要任务 | 20 |
| 紧急任务 | 30 |
| 完成一轮专注 | 15 |
| 解锁成就 | 50 |

每 100 XP 提升 1 级。

### Combo

默认连击窗口为 5000 毫秒。连续完成任务会叠加连击，连击时会额外增加 XP。

### 成就

内置成就包括：

- 初次出击：完成第 1 个任务。
- 小试牛刀：完成 10 个任务。
- 效率达人：完成 50 个任务。
- 任务终结者：完成 100 个任务。
- 三连击：达成 3 连击。
- 五杀：达成 5 连击。
- 无人能挡：达成 10 连击。
- 崭露头角：达到 Lv.5。
- 久经沙场：达到 Lv.10。

## 开发说明

### 常用脚本

```bash
npm start
```

启动 Electron 应用。

```bash
npm run rebuild
```

重建 `better-sqlite3` 原生模块。

```bash
npm run build
```

使用 `electron-builder` 打包 macOS DMG。

### IPC 通道

主要 IPC 通道：

| 通道 | 说明 |
| --- | --- |
| `get-tasks` | 获取当前任务列表 |
| `save-tasks` | 保存当前任务列表 |
| `get-game-state` | 获取游戏状态 |
| `save-game-state` | 保存游戏状态 |
| `toggle-collapse` | 折叠或展开主窗口 |
| `resize-window` | 根据内容高度调整主窗口 |
| `get-settings` | 获取设置 |
| `save-settings` | 保存设置 |
| `open-settings` | 打开控制中心 |
| `close-settings` | 关闭控制中心 |
| `db-add-record` | 写入任务历史 |
| `db-complete-record` | 标记任务完成 |
| `db-delete-record` | 标记任务删除 |
| `db-get-stats` | 获取看板统计 |
| `db-get-history` | 获取历史记录 |

### 安全设置

窗口配置启用了：

- `contextIsolation: true`
- `nodeIntegration: false`

渲染层必须通过 `preload.js` 暴露的 `window.api` 与主进程交互。

## 已知注意事项

- 当前项目主要面向 macOS，`vibrancy`、透明窗口、托盘图标模板等效果在其他系统上可能不同。
- `better-sqlite3` 是原生依赖，Electron 或 Node 版本变化后可能需要重新执行 `npm run rebuild`。
- 开发环境不建议提交 `node_modules`，应通过 `npm install` 从 `package-lock.json` 还原依赖。
- 生产打包如果需要签名、公证、自动更新，需要继续补充 `electron-builder` 配置。
- 远程字体来自 Google Fonts，离线环境下字体可能回退到系统默认字体。
